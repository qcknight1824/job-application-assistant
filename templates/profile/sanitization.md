# Sanitization rules.

Mandatory for all external outputs. Run the forbidden-term check (case-insensitive) before saving any resume, cover letter, or response.

## REPLACEMENTS

| Internal | External |
|---|---|
| <internal product name> | <generic description, e.g. "continuous monitoring platform"> |
| <internal system name> | <category, e.g. "GRC platform"> |
| <named regulation / client> | <e.g. "a regulatory control", "a top-10 retail client"> |
| <internal team acronym> | <plain description> |

## FORBIDDEN TERMS (must not appear in external outputs)

<term>, <term>, <colleague surnames>, <internal URL fragments>, <internal identifiers>

Allowed: employer names, public technologies and tools.

## OTHER RULES

- No customer data or system identifiers.
- Do not imply unapproved plans are approved.
- Unverified and Immature metrics are not used externally.
